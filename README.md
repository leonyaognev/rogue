# 🗡️ Rogue — Console Roguelike

Ты — отважный искатель приключений, спустившийся в подземелье древнего замка. Твоя цель — пройти **21 уровень**, собрать как можно больше сокровищ и остаться в живых.

> Классическая roguelike-игра в стиле оригинального Rogue 1980 года. Выживи, собирай добычу, побеждай монстров!

---

## ✨ Особенности

- **21 уровень подземелий** — каждый уровень генерируется заново
- **Пошаговая боевая система** — продумывай каждый ход
- **5 типов монстров** с уникальными способностями
- **Система предметов**: оружие, зелья, свитки, еда, сокровища
- **Туман войны** — видишь только то, что рядом
- **Таблица рекордов** — соревнуйся с другими игроками
- **Сохранение и загрузка** — продолжишь с того места, где остановился

---

## 🚀 Установка и запуск

```bash
# Установи зависимости
npm install

# Запусти игру
npm start
```

## 🎮 Управление

### Перемещение

| Клавиша | Действие |
| ------- | -------- |
| `h`     | Влево    |
| `j`     | Вниз     |
| `k`     | Вверх    |
| `l`     | Вправо   |

> Классика! Vim-стиль `h j k l` — как настоящие хардкорные игроки.

### Предметы

| Клавиша | Действие                   |
| ------- | -------------------------- |
| `f`     | Съесть еду                 |
| `r`     | Выпить зелье               |
| `w`     | Надеть/использовать оружие |
| `s`     | Прочитать свиток           |

### Прочее

| Клавиша | Действие         |
| ------- | ---------------- |
| `b`     | Таблица рекордов |
| `q`     | Выйти из игры    |

## 👾 Враги

| Монстр       | Символ | Особенности                                               |
| ------------ | ------ | --------------------------------------------------------- |
| **Зомби**    | `z`    | Много здоровья, медленный, но живучий                     |
| **Вампир**   | `v`    | Крадёт здоровье при атаке, уворачивается от первого удара |
| **Призрак**  | `g`    | Телепортируется, невидим вне боя                          |
| **Огр**      | `O`    | Ходит по 2 клетки, отдыхает после атаки                   |
| **Змей-маг** | `s`    | Двигается по диагонали, может усыпить                     |

## 🎒 Система предметов

- **Оружие** — повышает урон в бою
- **Зелья** — можно активировать для временных эффекта
- **Свитки** — улучшают характеристики (сила, ловкость)
- **Еда** — восстанавливает здоровье
- **Сокровища** — добавляют очки в таблицу рекордов

## 🏗️ Архитектура

Проект построен на принципах **чистой архитектуры**:

```
src/
├── index.js              # Точка входа
├── app.js                # Настройка приложения
├── game.js               # Игровой цикл
├── constants.js          # Конфигурация
└── services/
    ├── domain/           # Игровая логика
    │   ├── characters/   # Игрок и враги
    │   ├── level.js      # Генерация уровней
    │   ├── room.js       # Комнаты
    │   ├── corridor.js   # Коридоры
    │   └── inventory.js  # Инвентарь
    ├── presentation/     # Интерфейс
    │   ├── 2d/           # 2D рендеринг
    │   └── input.js      # Обработка ввода
    └── datalayer/        # Сохранения
        └── saveManager.js
```

## 🎯 Как играть

1. **Спустись в подземелье** — каждый уровень сложнее предыдущего
2. **Собирай сокровища** — они добавляются к твоему счёту
3. **Борись с монстрами** — используй оружие и зелья с умом
4. **Не забывай есть** — голодный герой — мёртвый герой
5. **Достигни 21 уровня** — и ты победишь!
