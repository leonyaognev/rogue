# Rogue

Консольная рогалик-игра на JavaScript с использованием библиотеки blessed. Вдохновлена классическим Rogue 1980 года.

## Возможности

- 21 уровень подземелий с процедурной генерацией
- Пошаговая боевая система
- 5 типов врагов с уникальным поведением
- Система предметов: оружие, зелья, свитки, еда, сокровища
- Туман войны и линия видимости
- Сохранение и загрузка
- Таблица рекордов

## Установка и запуск

```bash
npm install
npm start
```

## Управление

| Клавиша | Действие            |
| ------- | ------------------- |
| W/A/S/D | Перемещение         |
| h       | Использовать оружие |
| j       | Съесть еду          |
| k       | Выпить зелье        |
| e       | Прочитать свиток    |

## Структура проекта

```
src/
├── index.js              # Точка входа
├── app.js                # Настройка приложения
└── services/
    ├── domain/           # Игровая логика
    │   ├── characters/   # Персонажи (игрок, враги)
    │   ├── item.js       # Предметы
    │   ├── room.js       # Комнаты
    │   ├── corridor.js   # Коридоры
    │   ├── level.js      # Уровни
    │   └── inventory.js  # Инвентарь
    ├── presentation/     # Интерфейс
    │   ├── 2d/           # 2D рендеринг
    │   ├── 3d/           # 3D режим
    │   └── input.js      # Ввод
    └── datalayer/        # Сохранения
        └── save_manager.js
```

## Враги

| Тип      | Символ | Особенности                                         |
| -------- | ------ | --------------------------------------------------- |
| Зомби    | z      | Много HP, низкая ловкость                           |
| Вампир   | v      | Крадёт HP, первый удар по нему всегда промахивается |
| Призрак  | g      | Телепортируется, невидим вне боя                    |
| Огр      | O      | Ходит по 2 клетки, отдыхает после атаки             |
| Змей-маг | s      | Диагональное движение, может усыпить                |

## Архитектура

Проект построен на принципах чистой архитектуры:

- **Domain** — игровая логика, не зависит от внешних слоёв
- **Presentation** — рендеринг и обработка ввода
- **Datalayer** — работа с файловой системой (сохранения)
